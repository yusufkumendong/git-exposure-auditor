# Changelog

## 3.1.0-rc1

- Input langsung `--domain`, `--subdomain`, `--target`, dan `--wildcard`; TXT tidak wajib.
- Scope otomatis dari direct input.
- Passive wildcard discovery melalui subfinder atau crt.sh dengan host limit.
- Random-path baseline per target.
- Soft-404, SPA fallback, custom error, WAF/CDN, rate-limit, redirect, upstream, dan network classification.
- Confidence score dan evidence hash.
- Retry, exponential backoff, dan numeric Retry-After support.
- Proxy, custom header, compression, HTTP version selection.
- JSONL/CSV/TXT dan HackerOne candidate Markdown report.
- Private/reserved DNS resolution guard.
- Test baru untuk input dan response classifications.

## 3.0.0

- Arsitektur Bash modular awal.
- Easy, Medium, Hard, dan Best Practice.
- Git signature validation dan exact HTTP statistics.
